#Use Cases - VGPlanner

##1. Управление целями (VGoals)

Use Case	Команда/Запрос	Описание
Создать цель	CreateGoalCommand	Создание новой цели с названием, описанием, приоритетом. Можно указать родительскую цель.
Редактировать цель	UpdateGoalCommand	Изменение названия, описания, приоритета, статуса.
Удалить цель (мягкое)	DeleteGoalCommand	Установка IsDeleted = true. Проверка на дочерние элементы.
Получить дерево целей	GetGoalTreeQuery	Получение иерархической структуры всех целей пользователя с вложенными целями и задачами.
Получить плоский список целей	GetGoalsListQuery	Получение всех целей пользователя (без вложенности) с пагинацией и фильтрацией.
Переместить цель	MoveGoalCommand	Изменение ParentGoalId для перемещения в другую родительскую цель.
Изменить статус цели	ChangeGoalStatusCommand	Изменение статуса (New → InProgress → Completed → Archived).
Получить цель по ID	GetGoalByIdQuery	Получение полной информации о цели со всеми дочерними элементами.

##2. Управление задачами (VTasks)
Use Case	Команда/Запрос	Описание
Создать задачу	CreateTaskCommand	Создание задачи внутри цели. Указание названия, описания, дедлайна, приоритета, тегов.
Редактировать задачу	UpdateTaskCommand	Изменение всех полей задачи (кроме GoalId и UserId).
Удалить задачу (мягкое)	DeleteTaskCommand	Установка IsDeleted = true. Проверка на связанные логи.
Получить задачи по цели	GetTasksByGoalQuery	Получение всех задач в конкретной цели (с пагинацией и фильтрацией по статусу).
Получить задачу по ID	GetTaskByIdQuery	Получение полной информации о задаче со всеми логами и расписанием.
Переместить задачу	MoveTaskCommand	Изменение GoalId для перемещения в другую цель.
Изменить статус задачи	ChangeTaskStatusCommand	Изменение статуса задачи с автоматической установкой StartedAt/CompletedAt.
Изменить порядок задач в цели	ReorderTasksInGoalCommand	Изменение OrderIndex для задач внутри одной цели (Drag-n-Drop).
Поиск задач	SearchTasksQuery	Глобальный поиск по названию, описанию, тегам.

##3. Управление расписанием (VDays + VDayVTask)
Use Case	Команда/Запрос	Описание
Получить/создать день	GetOrCreateDayQuery	Получение дня по дате. Если не существует — создается автоматически.
Назначить задачу на день	ScheduleTaskCommand	Привязка задачи к дню через VDayVTask с указанием порядка.
Снять задачу с дня	UnscheduleTaskCommand	Удаление связи между задачей и днем.
Изменить порядок задач в дне	ReorderDayTasksCommand	Изменение OrderIndex для задач в рамках одного дня (Drag-n-Drop).
Получить расписание на день	GetDayScheduleQuery	Получение всех задач, запланированных на конкретную дату (отсортированных по OrderIndex).
Получить расписание на неделю	GetWeekScheduleQuery	Получение задач на 7 дней (текущая неделя) с группировкой по дням.
Получить расписание на месяц	GetMonthScheduleQuery	Получение задач на месяц с группировкой по дням (календарный вид).
Получить задачи без расписания	GetUnscheduledTasksQuery	Получение всех задач, которые не назначены ни на один день.
Обновить заметку дня	UpdateDayNoteCommand	Изменение SpecialNote.

##4. Управление заметками (VNotifications)
Use Case	Команда/Запрос	Описание
Создать заметку	CreateNotificationCommand	Создание заметки для конкретного дня.
Редактировать заметку	UpdateNotificationCommand	Изменение названия, описания, дедлайна.
Удалить заметку	DeleteNotificationCommand	Полное удаление заметки.
Отметить как прочитанное	MarkNotificationAsReadCommand	Установка IsRead = true.
Отметить как выполненное	MarkNotificationAsCompletedCommand	Установка IsCompleted = true.
Получить заметки дня	GetDayNotificationsQuery	Получение всех заметок для конкретного дня.
Получить непрочитанные заметки	GetUnreadNotificationsQuery	Получение всех непрочитанных заметок пользователя.

##5. Логирование выполнения (VTaskLogs)
Use Case	Команда/Запрос	Описание
Добавить запись в лог	AddTaskLogCommand	Создание записи лога. Пользователь указывает: заметку, вложения, время, старый/новый статус (всё опционально, кроме задачи и дня).
Получить историю задачи	GetTaskHistoryQuery	Получение всех записей лога по задаче с сортировкой по дате — полная хронология работы.
Получить дневной отчет	GetDailyReportQuery	Получение всех записей лога за конкретный день с группировкой по задачам.
Получить отчет по времени	GetTimeReportQuery	Получение статистики по потраченному времени за период (день/неделя/месяц).
Получить прогресс по цели	GetGoalProgressQuery	Получение агрегированного прогресса (средний % выполнения задач в цели).
Редактировать запись лога	UpdateTaskLogCommand	Изменение заметки или вложений в существующей записи лога.

##6. Системный аудит (AuditLog)
Use Case	Команда/Запрос	Описание
Получить глобальный аудит	GetAuditLogsQuery	Получение всех системных событий с фильтрацией (по сущности, дате, действию).
Получить аудит по задаче	GetTaskAuditQuery	Фильтрация логов по конкретной задаче.
Получить аудит по цели	GetGoalAuditQuery	Фильтрация логов по конкретной цели.
Получить аудит по дню	GetDayAuditQuery	Фильтрация логов по конкретному дню.

##7. Dashboard и аналитика
Use Case	Команда/Запрос	Описание
Получить дашборд на сегодня	GetTodayDashboardQuery	Сводка: задачи на сегодня, выполненные задачи, прогресс по целям, потраченное время.
Получить статистику по статусам	GetStatusStatisticsQuery	Количество задач по статусам (New, InProgress, Done, Cancelled).
Получить статистику по приоритетам	GetPriorityStatisticsQuery	Количество задач по приоритетам (Low, Medium, High, Critical).
Получить просроченные задачи	GetOverdueTasksQuery	Задачи, у которых Deadline < Today и статус не Done.
Получить задачи на сегодня	GetTodayTasksQuery	Все задачи, запланированные на сегодня + просроченные.

Features/

│   ├── CreateGoal/

│   │   ├── CreateGoalHandler.cs
│   │   ├── CreateGoalValidator.cs
│   │   └── CreateGoalResponse.cs
│   ├── UpdateGoal/
│   └── GetGoalTree/
├── Tasks/
│   ├── CreateTask/
│   └── ScheduleTask/
├── Days/
│   └── GetDaySchedule/
└── Dashboard/
    └── GetTodayDashboard/
